## 1. Pitch Éclair (Elevator Pitch)

> **Hoot Indie Games** ([hootindiegames.com](https://hootindiegames.com/)) est un sanctuaire web gratuit dédié aux jeux vidéo indépendants. Il réunit **8 disciplines de déduction quotidiennes** (reconnaissance par capture d'écran, quiz déductif, frise chronologique, dé-pixellisation, critique Steam caviardée, blind test musical synthétisé), des **sprints Time Attack**, des **duels Versus 1v1 en direct** et une encyclopédie de **plus de 260 jeux indés**.

## 3. Publications pour LinkedIn (Tech, Craft & Portfolio)

### Post 1 : Lancement officiel & Récit de création (Storytelling)

```markdown
🎮 Comment créer un sanctuaire de jeux vidéo indépendants sans serveur lourd et 100% souverain ?

Après plusieurs mois de conception, de code et d'itérations, je suis très heureux de vous présenter **Hoot Indie Games** 🦉 : https://hootindiegames.com/

L'idée de départ était simple : les jeux vidéo indépendants méritent leur propre sanctuaire de célébration culturelle, au-delà des algorithmes des grandes boutiques.

J'ai donc imaginé une plateforme web réunissant :
• 8 disciplines de déduction quotidiennes (reconnaissance par capture, frise chronologique, critiques caviardées, blind test musical...).
• Un mode Duel 1v1 en direct et des sprints Time Attack compétitifs.
• Une encyclopédie interactive de plus de 260 pépites indés synchronisée avec les métadonnées officielles de Steam.

💡 **Les défis techniques et choix d'architecture :**
1. **Zéro latence en 1v1** : Arène multijoueur temps réel développée sur une architecture WebRTC P2P souveraine couplée à un relais léger OVHcloud (aucun serveur de jeu tiers coûteux, 0 popup de réseau local).
2. **Audio sans fichiers externes** : Un moteur de Blind Test utilisant la Web Audio API pour synthétiser en direct les bandes-son cultes (0 problème de droits d'auteur, 0 requête 404, chargement instantané).
3. **Performance & Éco-conception** : Stack React 19 + Tailwind CSS + Vite avec un pré-rendu SEO sémantique pour Googlebot et Bingbot.

C'est gratuit, sans publicité intrusive et conçu avec passion.

👉 Découvrez le site et testez la devinette du jour : https://hootindiegames.com/
Vos retours et critiques constructives sont les bienvenus !

#Gaming #WebDevelopment #React #IndieGames #GameDesign #TechCraft #Portfolio
```

### Post 2 : Focus Tech & Architecture Souveraine (Web Audio, WebRTC P2P)

```markdown
💡 [Tech Insight] Pourquoi nous avons synthétisé nos bandes-son en Web Audio plutôt que d'utiliser des MP3 ?

En développant le mode Blind Test de Hoot Indie Games (https://hootindiegames.com/), j'ai été confronté à un triple problème classique du web :
1. Les fichiers audio MP3 pèsent lourd sur le temps de chargement mobile.
2. Les flux streaming audio externes risquent des erreurs 404 ou des blocages CORS.
3. Les droits d'auteur et revendications bloquent souvent les créateurs qui streament le site.

🛠️ **La solution retenue :**
Recréer les arrangements emblématiques (Hollow Knight, Undertale, Celeste, Balatro...) directement en synthèse modulaire via la Web Audio API native des navigateurs :
• Oscillateurs (Sine, Square, Sawtooth) et filtres passe-bas modulés par enveloppe ADSR.
• Visualiseur spectral en temps réel synchronisé via un AnalyserNode.
• Poids total par morceau : moins de 2 Ko de code JavaScript au lieu de plusieurs Mo d'audio !

Résultat : un démarrage à la milliseconde, une fidélité rétro unique et une autonomie hors-ligne totale.

Le résultat s'écoute directement ici : https://hootindiegames.com/#blindtest

Curieux d'avoir vos retours sur ce type d'approche pour le web interactif !

#JavaScript #WebAudio #Frontend #WebPerf #IndieGames #React
```
